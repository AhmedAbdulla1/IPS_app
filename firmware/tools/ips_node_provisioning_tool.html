🛰️ أداة تجهيز نقاط الـIPS

توليد Node ID لكل جهاز، إرساله عبر USB، وتجميع بيانات الموقع لتصديرها لاحقًا لـSupabase. تعمل على Edge أو Chrome فقط (Web Serial API).

1. الاتصال بالجهاز

مش متصل لسه. دوس "اتصل بالجهاز" واختار المنفذ من نافذة المتصفح.

2. بيانات النود (المكان في المبنى)

3. توليد الـUID وإرساله للجهاز

الجهاز هيعمل إعادة تشغيل (reboot) تلقائيًا بعد ما يحفظ الـID - ده طبيعي.

4. سجل النودز المُجهّزة (هذه الجلسة فقط)

0 نود
# Node ID (hex) الاسم X Y الدور الوقت
⚠️ السجل ده مش متخزن دائمًا - لو قفلت الصفحة هيتمسح. صدّره بـCSV بعد كل مجموعة نودز عشان متفقدش البيانات، وارفعه لـSupabase يدويًا أو قولّي لما الاتصال يرجع نكمل الربط التلقائي.
